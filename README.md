# 병원 찾기 · AI 병원 안내 도우미 (시연용)

스마트인재개발원 핵심프로젝트 · 팀 독수리5형제

## 바로 보기
https://lee020304.github.io/goodoc-demo/

## 무엇인가
병원 예약 서비스 화면에 얹는 **AI 병원 안내 챗봇** 시연본입니다.
자연어로 말하면 조건을 이해해 병원을 찾아주고, 예약 창구까지 안내합니다.

```
"광주 남구 이비인후과"      -> 조건 검색
"감기 걸린 것 같아"          -> 진료과 안내 후 지역 확인
"지금 문 연 병원"            -> 현재 시각 기준 진료중인 곳
"주말에도 하는 소아과"       -> 주말 진료 필터
```

## 데이터
- 광주 지역 요양기관 2,692곳
- 건강보험심사평가원 병원정보서비스 · 의료기관별상세정보서비스 · 병원평가정보서비스
- 모두 실제 수집 결과이며 지어낸 값이 없습니다

전체 79,819곳으로 동작하는 버전은 별도 저장소(비공개)에 있습니다.

## 안내
본 서비스는 병원 선택을 돕는 정보 제공 서비스이며 의학적 판단을 대신하지 않습니다.
증상이나 병명을 입력해도 질병명·진단 표현은 생성하지 않고 진료과 안내로만 변환합니다.
