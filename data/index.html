진료시간이 전국 병원의 9.1% 뿐입니다.
병원이 심평원에 등록할 의무가 없어 대부분 비어 있습니다. 저희 수집 실수가 아닌지 확인하려고 빈 병원 130곳을 API로 다시 조회했고, 원래 등록되어 있지 않다는 것을 확인했습니다.
항목확보한 곳비율왜 없는가어떻게 확인했나우리 서비스에 미치는 영향
진료시간7,297곳9.1%병원이 심평원에 등록할 의무가 없어 대부분 비어 있음빈 곳 130개를 API 로 다시 조회해 ‘수집 누락이 아니라 미등록’임을 확인‘일요일에 하는 곳’ 검색이 전국 병원의 9.1%에만 적용됨

여쭙고 싶은 것

어떤 데이터를 더 확보하면 좋을지 조언 부탁드립니다.

  1. 진료시간이 9.1%뿐인데, 이 상태로 ‘시간 조건 검색’을 핵심 기능으로 두는 것이 맞을까요?현재는 정보가 없는 곳도 ‘미확인’으로 함께 보여주고 있습니다.
  2. 진료시간·주차를 보완할 다른 공개 데이터가 있을까요?지자체 데이터, 응급의료정보(E-Gen) 등을 검토해봐야 할지 궁금합니다.
  3. 병원별 리뷰를 확보할 방법이 있을까요?굿닥 사이트는 AI 크롤러를 robots.txt 로 차단하고 있어 수집 여부를 여쭙고 싶습니다.
  4. 증상 → 진료과 매핑에 참고할 공신력 있는 자료가 있을까요?정부 표준이 없어 대학병원 안내를 참고해 팀이 정리했습니다.
  5. 비급여 진료비 데이터를 추가하면 도움이 될까요?심평원에 비급여진료비정보 API 가 있는데 아직 쓰지 않았습니다.
